# Daali Pictures Frontend

Vite + React + TypeScript site for Daali Pictures.

## Pages

- `/` — Home
- `/productions` — Our Productions
- `/about` — Daali Dhananjaya
- `/sangha` — Abhimani Sangha

All page content uses local dummy data (no API calls).

## Scripts

```bash
npm install
npm run dev
npm run build
```

Path alias: `@/*` → `src/*`

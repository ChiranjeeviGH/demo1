# SKDRDP

Premium institutional website for Shri Kshetra Dharmasthala Rural Development Project. Built with React and Vite.

## Run

```bash
npm install
npm run dev
```

Open the local URL printed in the terminal (default `http://127.0.0.1:43221`).

```bash
npm run build
npm run preview
```

## Replace images

Put files in `src/assets/`:

- `hero.jpg`
- `founder.jpg`
- `leader-1.jpg` … `leader-6.jpg`
- `agriculture.jpg`, `women.jpg`, `healthcare.jpg`, `education.jpg`, `social-welfare.jpg`
- `story-farmer.jpg`
- `activity-1.jpg` … `activity-4.jpg`
- `karnataka-map.svg`

## Edit content

- Copy and section data: `src/data/`
- Colors and fonts: `src/index.css`
- Layout and motion: each `src/components/*.module.css`
